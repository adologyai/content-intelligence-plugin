# Screenshots

The plugin directory expects 3–5 product screenshots at **1280×800 PNG**
named in sort order so they display in the intended sequence.

## Required captures

1. `01-knowledge-set.png` — A knowledge set detail page showing feeds +
   sample items + labels. This is the "what the data looks like" shot.
2. `02-audit-report.png` — A generated audit report (the Glossier-style PDF
   or the in-app audit view) showing category fit, trends, gaps.
3. `03-workbench.png` — The workbench with insights → angles → concepts
   → scripts lineage visible.

## Recommended additional captures

4. `04-chatbot.png` — The chatbot answering a question with citations back
   to source posts.
5. `05-coaching.png` — Post coaching view with the "why it worked / why it
   didn't" narrative.

## Guidelines

- Capture from a real (or anonymized) tenant, not Lorem Ipsum
- Dark or light mode consistent across the set
- No leaked PII, customer names, or private data
- Optimize file size (TinyPNG or similar) to keep the bundle small
