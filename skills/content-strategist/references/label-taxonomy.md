# Label Taxonomy Reference

Adology classifies every piece of content across 50+ label dimensions. This reference documents the most important categories, what each measures, and which are most actionable for content strategy.

## Tier 1: High-Impact Strategy Labels

These categories have the strongest correlation to content performance decisions.

| Category | What It Measures | Actionable For |
|----------|-----------------|----------------|
| **HookPrimaryCategory** | The primary opening technique (Question, Challenge, Statistic, BoldClaim, Storytelling, Demonstration) | Script writing, first 3 seconds |
| **VisualExecutionStyle** | Production approach (UGC, Professional, Tutorial, Talking Head, B-Roll Montage) | Production planning, budget allocation |
| **CreativeConcept** | Storytelling format (Before/After, Day-in-the-Life, Comparison, Unboxing, Testimonial) | Content ideation, campaign concepts |
| **CTAActionType** | What action is prompted (ShopNow, LearnMore, SwipeUp, FollowForMore, CommentBelow) | Conversion optimization |
| **FunnelAlignment** | Funnel position (Awareness, Consideration, Conversion) | Media planning, content mix |
| **TonalQualities** | Emotional tone (Humorous, Educational, Inspirational, Provocative, Calm) | Brand voice calibration |

## Tier 2: Production and Format Labels

These categories guide execution decisions.

| Category | What It Measures |
|----------|-----------------|
| **Pacing** | Content speed and rhythm (Fast, Medium, Slow, Variable) |
| **CameraMovement** | Camera technique (Static, Handheld, Cinematic Pan, Close-up) |
| **LightingQuality** | Production lighting (Natural, Studio, Mixed, Low-light) |
| **SoundDependency** | Whether content requires audio to communicate (Sound-On, Sound-Off Friendly, Music-Driven) |
| **Caption/SubtitleRequirement** | How captions are used (Burned-in, Auto-generated, None) |
| **AspectRatio** | Content dimensions (9:16, 1:1, 16:9, 4:5) |
| **VideoDurationCategory** | Length classification for video content |
| **TextOverlayProminence** | How much text appears on screen |
| **ColorScheme** | Dominant visual palette |
| **Animation&VisualEffects** | VFX and animation usage |

## Tier 3: Audience and Context Labels

These categories inform targeting and positioning.

| Category | What It Measures |
|----------|-----------------|
| **DemographicAge** | Target age bands within generational groups |
| **DemographicLifestyle** | Audience interests and identity-driven characteristics |
| **Interest/PassionCategory** | Content affinity categories |
| **EconomicSegment** | Implied economic positioning |
| **CulturalContext** | Cultural, temporal, or geographic references |
| **AgeAppropriatenessRating** | Content sensitivity and age suitability |

## Tier 4: Persuasion and Messaging Labels

These categories analyze the messaging strategy.

| Category | What It Measures |
|----------|-----------------|
| **CTAFraming** | Psychological CTA positioning (Urgency, Curiosity, Social Proof, FOMO) |
| **Persuasion** | Persuasion technique used |
| **BrandPositioningType** | Strategic brand differentiation approach |
| **MessageType** | Core message classification |
| **NarrativeStructure** | Story arc structure |
| **ProblemType** | What problem the content addresses |
| **SolutionPositioning** | How the solution is framed |
| **TrustMechanism** | How credibility is established (Testimonial, Expert, Data, Social Proof) |
| **ShareabilityFactors** | Elements that drive sharing behavior |
| **MarketingObjective** | The specific marketing goal |

## High-Performance Combinations

Certain label combinations consistently signal high performance:

- **Question Hook + UGC Format + Humorous Tone** -- Strong for awareness on TikTok
- **Statistic Hook + Professional Format + Educational Tone** -- High performance for consideration on LinkedIn/YouTube
- **BoldClaim Hook + Before/After Concept + Conversion CTA** -- Effective for direct response
- **Storytelling Hook + Talking Head + Inspirational Tone** -- Drives high shareability

When analyzing combinations, use the label combination cross-tabulation data to find which specific A+B pairings over-index on engagement. Combinations with a high efficiency index and sufficient sample size (count > 10) are the most reliable signals.

## Which Categories Are Most Actionable

For a content creator building a brief:
1. Start with **HookPrimaryCategory** -- this determines the first 3 seconds
2. Choose **VisualExecutionStyle** -- this sets production approach and budget
3. Set **TonalQualities** -- this calibrates the brand voice
4. Define **CTAActionType** -- this determines the conversion path
5. Confirm **FunnelAlignment** -- this ensures the content matches the campaign objective

Everything else provides refinement and optimization context.
