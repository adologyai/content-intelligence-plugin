BLOCK RECIPE: Market Signals (Page 2)
======================================
Page Type: Portrait 8.5×11in — Market intelligence dashboard with news headlines,
           community sentiment, hook/brand analytics, paid presence, and action board.
Layout: Nav → Header Band → [News (L) + Community (R)] → [Hook Chart + Combos (L) +
        Brand Leaderboard + Paid Presence (R)] → Action Board (3 cards) → Footer

INPUTS
------
  project_id     = [Project ID, from list_projects]
  primary_brand  = [Primary brand name, e.g. "EXAMPLE_PRIMARY_BRAND"]
  project_name   = [Project display name, e.g. "EXAMPLE_PROJECT_NAME"]
  week_start     = [Monday date, e.g. "2026-03-24"]
  week_end       = [Sunday date, e.g. "2026-03-30"]

ANALYSIS PROMPT
---------------

STEP 1 — PULL NEWS HEADLINES (5 items)
  Use web search to find 4–6 industry news headlines from the past 7 days
  relevant to the competitive set. Search queries:
    - "{category} industry news {week_start}"
    - "{primary_brand} news"
    - Each tracked competitor brand name + "news"

  For an earned-media read that goes beyond headlines, `seo_mentions` returns web
  mentions of a brand with source domain, authority rank, page type, and snippet —
  useful for the "who is writing about whom" signal behind a headline.

  For each headline, classify the strategic signal:
    - "Threat"      → Competitor gaining ground (red badge, signal-threat)
    - "Your Brand"  → News about the primary brand (green badge, signal-internal)
                      If "Your Brand" → mark alert=true for dark-bg card
    - "Watch"       → Industry shift to monitor (yellow badge, signal-watch)
    - "Opportunity" → Opening for primary brand (lime badge, signal-opportunity)

  Each news item:
    { headline, source, signal_class, signal_label, url, alert (bool), so_what }

  so_what = One sentence: "Why this matters for {primary_brand}. Strategic implication."

STEP 2 — PULL COMMUNITY INTELLIGENCE (4 items)
  Call `analyze` with:
    - projectId    = project_id
    - query        = "what the audience is saying about {category} and {primary_brand}"
    - feedTypes    = ["discussion"]
    - distribution = "top"
    - limit        = 20
  Reddit threads read straight through. If comments on the brand's own
  TikTok/Instagram posts have been brought into the pool by a `fetch_comments`
  run, add includeComments = true and platformFilter to read those too.

  Select the top 4 most strategically relevant.

  For each clipping:
    { theme, quote, source, so_what }

  theme  = Short label (3-5 words, e.g. "Your product is being duped")
  quote  = Verbatim excerpt in quotes from the post
  source = The community/thread name + its engagement (e.g. "r/{subreddit} · 103 upvotes")
  so_what = Strategic implication for the primary brand (1 sentence)

STEP 3 — COMPUTE HOOK PERFORMANCE CHART (6 rows)
  Call `list_labels` with projectId = project_id to learn the scope's dimension
  names, then call `get_table_data` with:
    - projectId  = project_id
    - rows       = [the hook dimension name]
    - columns    = "focalVsRest"
    - focalBrand = primary_brand
    - feedTypes  = ["brand"]
    - metrics    = ["count", "useRate", "medianLikes", "viralRate"]
    - startDate  = week_start
    - endDate    = week_end
    - topN       = 15

  From the hook distribution in the response, extract:
    For each hook value (up to 6, sorted by medianLikes descending):
      - name: Hook value name
      - median_likes: medianLikes for this hook
      - usage_pct: useRate — % of posts using this hook
      - bar_width_pct: Round(median_likes / max_median * 100, 1) — largest = 100%
      - signal: IF usage_pct < 5 AND median_likes > category_median × 1.3:
                  "UNDERUSED · HIGH ROI" (highlighted badge)
                ELSE: null

STEP 4 — COMPUTE HOOK × FORMAT COMBOS (4 rows)
  Call `get_table_data` again with rows = [hook dimension, format dimension] —
  a two-dimension row spec builds the composite table directly. Take the top 4
  combinations by medianLikes:
    { combo_name, median_likes, post_count }

  combo_name    = "{Hook} + {Format}" (e.g. "Curiosity Gap + Branded Montage")
  bar_width_pct = relative to the largest combo (largest = 100%)

STEP 5 — COMPUTE BRAND ENGAGEMENT LEADERBOARD (up to 8 brands)
  Call `aggregate` with:
    - projectId = project_id
    - groupBy   = ["brand"]
    - measures  = [{ field: "*", fn: "count", as: "n" },
                   { field: "likes", fn: "median", as: "medianLikes" }]
    - filters   = { feedType: ["brand"], from: week_start, to: week_end,
                    excludeBoosted: true }
    - sort      = [{ by: "medianLikes", dir: "desc" }]

  This is a ranking call, so the response comes back split. Build the leaderboard
  from `rows` only. A brand that landed in `directionalRows` sat below the
  reliability floor — it may be mentioned in prose with its `n` stated, but it
  does not take a leaderboard position.
    { rank, name, median_likes, post_count, bar_width_pct, is_primary }

  is_primary    = true for the primary brand (highlighted row)
  bar_width_pct = relative to largest brand (largest = 100%)
  Header note: "This week · Organic only" — excludeBoosted made that true, so say it.

STEP 6 — PULL PAID PRESENCE (5 brands)
  Run the Step 5 `aggregate` call a second time WITHOUT filters.excludeBoosted.
  Per brand, boosted_count = (count without the filter) − (count with it): the
  posts that brand declared boosted this window. Take the top 5 by boosted_count:
    { brand, count, msg, persist, persist_label }

  msg           = Brief description of what those boosted posts push, from their headlines
  persist_label = How far back the brand's boosted run goes in the window:
                  earliest boosted post > 30 days old → "30+ days" (persist-high)
                  > 7 days old  → "14 days" (persist-med)
                  otherwise     → "3 days" or "7 days" (persist-new)

  If the team has a connected ad account, `list_ad_accounts` then
  `get_creative_leaderboard` gives the primary brand's OWN paid performance
  (spend, ROAS, CTR) with inline creative media — a stronger block when it's
  available. With no connected account, keep the boosted read above.

STEP 7 — GENERATE ACTION BOARD (3 cards)
  Using all intelligence from Steps 1–6, generate three strategic actions:

  Card 1 — DEFEND (forest green background):
    What threat requires immediate response?
    play_action = Imperative sentence (e.g. "Own 'gentle skincare' on TikTok before Rhode claims it")
    play_detail = 2-3 sentences with specific data points from the analysis

  Card 2 — ATTACK (olive background):
    What opportunity can the brand seize this week?
    play_action = Imperative sentence
    play_detail = 2-3 sentences with supporting data

  Card 3 — WATCH (dark background):
    What signal should the brand monitor?
    play_action = Imperative sentence
    play_detail = 2-3 sentences with context

STEP 8 — BUILD HTML BLOCKS
  For repeating elements (news cards, clippings, chart rows, brand rows, paid rows,
  play cards), generate the HTML per the patterns in the render package comments,
  then substitute the full blocks into their placeholders.

OUTPUT: Fill the Output Schema (P2_output_schema.yaml) with all computed fields.
RENDER: Substitute values into the Render Package (P2_render_package.html).
        Render final HTML via WeasyPrint to produce the page.
